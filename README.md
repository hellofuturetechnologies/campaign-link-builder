# Campaign Link Builder

A free browser tool from Hello Future Technologies for generating UTM links across marketing channels.

## Use the tool

1. Enter the destination URL and campaign name.
2. Enter one source and medium per line, such as `newsletter,email` or `linkedin,organic_social`.
3. Generate the links, then copy them individually or download a CSV.

Optional term and content values apply to every channel in the batch. Existing destination parameters and fragments are preserved. Existing UTM values are replaced by the current campaign settings. A blank optional field clears that parameter.

The tool runs locally in your browser and does not send campaign inputs to a server. UTM parameters help identify traffic in an analytics system when the destination is configured to measure it.

## Run locally

Open `index.html` in a browser. Clipboard access depends on browser permissions. You can also select and copy the displayed link.
